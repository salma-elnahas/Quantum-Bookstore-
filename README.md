 Quantum Bookstore is a basic Java application that simulates an online bookstore.
 It supports different types of books such as paper book and ebook and allows adding, removing, and purchasing them.
 each book has its ISBN, title, year, and price. And, Shipping service class for paperbooks to be shipped and mail service class
 for ebooks to be sent to handle sending logic (just prints for now).
